RemoteFinder 首个可下载安装的公开版本。macOS 11+，同一个 Universal 包包含 Apple Silicon 和 Intel 两种架构。

## 下载与安装

- **[下载 DMG 安装包](https://github.com/chansigit/remotefinder/releases/download/v0.2.0/RemoteFinder-0.2.0-macOS-universal.dmg)**：打开后把 RemoteFinder 拖到 Applications，再从「应用程序」启动。
- **[下载 ZIP 备用包](https://github.com/chansigit/remotefinder/releases/download/v0.2.0/RemoteFinder-0.2.0-macOS-universal.zip)**：解压后把 RemoteFinder.app 移到「应用程序」。
- **[安装与权限指南](https://github.com/chansigit/remotefinder/blob/v0.2.0/docs/INSTALL.md)**：安装包内也附有「安装与权限说明.txt」。
- **[SHA-256 校验文件](https://github.com/chansigit/remotefinder/releases/download/v0.2.0/SHA256SUMS.txt)**。

普通用户下载上面的 DMG 或 ZIP 即可，不需要下载 GitHub 自动生成的 Source code，也不需要安装 Xcode。

## 首次启动与权限

**此版本仅使用 ad-hoc 本地签名，尚无 Developer ID 签名或 Apple 公证。** macOS 可能提示无法验证开发者或无法检查恶意软件。

确认下载来源并决定运行后，先尝试打开一次应用，再到 **系统设置 → 隐私与安全性 → 仍要打开（Open Anyway）** 按提示确认。macOS 11–12 在「系统偏好设置 → 安全性与隐私 → 通用」中处理。受管理的 Mac 可能需要管理员批准。参见 [Apple 官方说明](https://support.apple.com/102445)。

正常使用无需授予屏幕录制、辅助功能或完整磁盘访问。私钥权限、文件夹访问、主机指纹、VPN 和连接失败的排查方法见上面的安装指南。不要为安装此应用全局关闭 Gatekeeper 或 SIP。

## 功能

- 浏览 SSH / SFTP 目录，双击文件下载后用本地默认应用打开。
- 点击路径栏逐级导航；点击末尾空白或按 ⌘L 编辑路径，Return 跳转、Esc 取消。
- 保存目录收藏、常用连接和最近连接；支持新建、编辑连接。
- 重命名远程文件和目录，避免覆盖已有同名项目。
- 密钥、SSH agent、密码和 keyboard-interactive 认证，沿用系统 SSH 配置。
- 青绿色原生界面、紧凑文件列表、按钮提示和 CRT 电脑图标。

## 验证与限制

72 项核心检查与路径栏交互检查通过；安装包经过双架构检查、ad-hoc 签名校验与 DMG 完整性检查。自动测试和运行检查在 Apple Silicon 上完成，Intel 真机及全部支持的 macOS 版本尚未逐一验证。

本地修改不会同步回服务器；暂不支持上传、删除、Finder 挂载或断点续传。远程重命名会改变服务器路径，请留意依赖旧路径的脚本或链接。
